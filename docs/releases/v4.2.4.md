# v4.2.4：课程缓存管理

在插件设置点击“打开缓存管理”，查看文字数量与内容大小估算，选择任务根目录或其子目录，确认范围后清理。

- 最终确认显示完整路径、份数、大小；可取消。
- 清理前暂停收尾并关闭网盘任务页及 ZIP 打包页，避免与提取/打包同时读写。
- 精确匹配目录边界，保留其他任务目录；只清理浏览器缓存，**已下载 ZIP、MD 和网盘视频不受影响**。
- 清理日志支持故障恢复；被清理文字的任务标为可重试，回原目录点“重试失败”重新提取。
- 大小按文字及元数据 UTF-8 字节数估算，不含索引等数据库开销。

## 安装或更新

下载本页 `baidu-netdisk-transcript-exporter-v4.2.4.zip`，解压后选择直接包含 manifest.json 的文件夹加载。更新时先暂停收尾并导出 ZIP，将新包覆盖到原加载目录，在 chrome://extensions 或 edge://extensions 点击重新加载，再刷新网盘页。不要先卸载，以免丢失缓存。

提供 SHA256SUMS.txt 校验文件。Source code ZIP 是开发源码，不是推荐安装包。

## 验证与边界

发布工作流要求 Windows/Linux × Node 22/24 逻辑与包验证、真实 Chromium 扩展回归通过。浏览器回归验证清理/取消、其他目录隔离、ZIP/MD 字节保留和重新提取，使用合成网页和独立临时浏览器，不访问真实账号。网页变化与正文完整性仍需实际使用核验。
