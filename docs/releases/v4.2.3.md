## 文稿与字幕导出 4.2.3

新增自动验证与可重复发布，提取流程沿用 4.2.2。

- Windows/Linux × Node 22/24 离线测试、语法/版本/运行引用检查。
- 独立 Chromium 从安装 ZIP 加载扩展，验证设置、手动视频隔离、延迟/预览文稿、MOV 字幕补提、中断记录、缓存恢复和单个 MD ZIP 下载。网络数据是合成夹具，不需要百度账号；不是在线服务兼容认证。
- 版本化打包脚本、固定文件清单、重复构建一致性、CRC、SHA-256 及自动标签发布。
- 完善安装/升级、开发/贡献、安全报告、隐私和上游授权核查说明。

### 下载与升级

从 Assets 下载 **baidu-netdisk-transcript-exporter-v4.2.3.zip**，解压至固定目录，在 Chrome/Edge 扩展管理页开启开发者模式，加载直接包含 manifest.json 的目录。无需 npm。

升级用户先暂停并导出阶段 ZIP，再覆盖原加载目录、重新加载扩展和刷新网盘页；不要先卸载。附件 SHA256SUMS.txt 用于校验。安装包不是商店签名 CRX。
