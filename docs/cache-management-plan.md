# 课程缓存管理设计与执行计划

用户已确认：显示缓存大小、按课程目录清理、删除前确认，保留已下载 ZIP/MD，并测试发布。

采用独立扩展管理页（从设置打开），保持暖白/绿色视觉。相比把长目录挤进弹窗，此方案可显示完整路径；相比只支持全部清空，可选择任务根目录或其子目录。

大小定义为缓存记录 JSON 的 UTF-8 字节估算，包含正文与元数据，不宣称为磁盘精确占用。按任务根目录分组，选择子目录时包含后代、使用路径段边界，不误匹配同名前缀或其他任务根目录。

确认显示根目录、子目录、份数、估算大小和重新提取后果。后端只允许本扩展 cache.html 发起管理请求。清理前要求所有网盘目录/视频页与打包页关闭；不自动关用户页面。后台串行处理，预览签名变化需重新确认。写入持久清理日志后按确定的键删除，重启后重放日志、修正检查点和旧任务回执；无法写日志时不删除。只操作扩展缓存及相关进度，不调用下载删除 API。
